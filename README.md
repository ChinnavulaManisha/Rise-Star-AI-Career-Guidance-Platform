# 🎓 RiseStar AI Career Guidance

**RiseStar** is a web-based AI career counseling platform designed to make career guidance accessible to every student. It leverages AI to provide personalized career recommendations based on aptitude assessments, interests, academic performance, and skills. The platform also includes an AI-powered chatbot for instant career guidance and an AI-based resume analyzer to help students improve their resumes and enhance their employability.

---

## ✨ Features

- 🤖 AI-powered personalized career recommendations
- 📝 Aptitude assessment and skill evaluation
- 🎯 Career suggestions based on interests and academic performance
- 🛣️ Detailed career roadmap with required skills, certifications, and learning resources
- 💬 AI Career Chatbot for instant career guidance and query resolution
- 📄 AI Resume Analyzer with feedback and improvement suggestions
- 📊 Student dashboard to view assessments, recommendations, and career progress
- 📱 Responsive and user-friendly interface

---

## 🛠 Tech Stack

- **Frontend:** HTML, CSS, Tailwind CSS, JavaScript
- **Backend:** Laravel (PHP)
- **Database:** MongoDB
- **AI Integration:** OpenAI API
- **Tools:** VS Code, Git, Composer, XAMPP/LAMP/WAMP
